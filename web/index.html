OpenWav Media Browser

High-performance audio plugin & standalone sample manager featuring an interactive 3D sample cloud constellation, multi-tag filtering, and DAW drag-and-drop.

Download Binaries Source Code
Overview

Key Capabilities

3D Sample Constellation

Visually browse WAV files in 3D space organized by acoustic timbre and spectral similarity.

Async Scanner

Scans large sample libraries in seconds asynchronously without blocking audio playback.

DAW Drag & Drop

Drag samples directly into Ableton Live, FL Studio, Logic Pro, Reaper, or Bitwig.

Tag-Based Filtering

Multi-tag searching, folder path management, auto-inference, and hidden file filtering.

VST3 & Standalone

Use OWMB as a 64-bit DAW plugin or as a standalone desktop application.

JUCE 8 Engine

Written in modern C++17 with JUCE 8 for low latency, cross-platform performance.
